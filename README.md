# 自动深浅壁纸 (BYD Auto Dark Wallpaper)

一款专为 **比亚迪车机（DiLink 横屏座舱）** 打造的自动切换壁纸工具。  
无需 Root 或系统特殊权限，应用会实时跟随车机的日间 / 夜间模式自动更换桌面壁纸，同时支持 **静态图片** 与 **视频动态壁纸**，界面贴合车机原生设计并随车机自动切换浅色 / 深色主题。

---

## 功能特色

- **全自动随车机日夜切换**：实时同步车机「日间 / 夜间」状态（兼容车机手动切换与自动模式），支持开机 / 上电自启。
- **双模式可选**：
  - **直接修改壁纸（默认）**：直接替换系统桌面静态壁纸（仅支持图片）。首次开启前会自动备份您当前的系统壁纸，关闭开关后自动复原。
  - **动态壁纸模式**：同时支持**静态图片**与**视频壁纸**，日夜切换时带有平滑渐变过渡效果；视频默认完全静音，不会打扰音乐和导航播报，并在切到其他界面时自动暂停以降低功耗。
- **独立日间 / 夜间壁纸库**：
  - 分别管理日间与夜间壁纸，支持一次多选导入图片或视频。
  - **无损取景剪裁**：静态图片支持按车机横屏比例自由拖动与缩放调整桌面可见区域（保留原图无损，随时可重新调整或恢复默认居中；**直接修改壁纸** 与 **动态壁纸模式** 均同步生效）。
  - 导入本地视频**不受车机相册 20 秒时长限制**。
  - 日间和夜间可分别设置 **「指定」**（固定使用选中的那张）或 **「随机」**（每次日夜切换或车机上电启动时自动换一张）。
- **内置运行日志**：支持在应用内开启调试日志，一键复制或导出日志到 U 盘，方便问题排查。

## 环境要求

- **适用设备**：比亚迪 DiLink 车机（已在 Di150VCP / Android 14 / Theme 7.0.0 实车验证）
- **系统要求**：Android 9.0（API 28）及以上
- **权限说明**：无需 Root、无需 ADB 激活或系统签名

## 快速上手

### 1. 添加日间与夜间壁纸
1. 打开应用，在左侧导航栏点击 **「壁纸」**。
2. 顶部可切换 **「日间」** 与 **「夜间」** 分页，点击 **「添加」**（支持一次多选本地图片或视频）。
3. 静态图片如需调整桌面构图（如竖图避免头部被裁、躲避桌面卡片遮挡），可点击卡片右上角 **裁剪图标** 或长按卡片选择 **「调整取景」**（原图保留，可随时恢复默认居中）。
4. 在对应分页下选择选取策略：
   - **指定**：点击某张壁纸即可设为固定使用。
   - **随机**：每次系统日/夜模式切换或车机开机上电时，自动从当前分页壁纸中随机更换（尽量不连续重复）。

### 2. 选择切换模式
在左侧 **「主页」** 的「切换模式」区域二选一：
- **直接修改壁纸**（适合仅使用静态图片）：无需额外设置，直接打开总开关即可使用。
- **动态壁纸模式**（适合使用视频壁纸，或希望图片切换带渐变效果）：选中该模式后，点击下方的 **「去激活」**，在系统弹出的壁纸设置页中将 **「自动深浅动态壁纸」** 设为系统桌面壁纸。

### 3. 开启自动切换
- 在 **「主页」** 打开顶部 **「自动深浅壁纸」** 总开关即可生效。
- 车机开机 / 上电自启状态会直接跟随总开关，无需额外设置。
- 页面右上角的 **`!` 感叹号按钮** 可随时查看功能说明、当前原壁纸备份状态及最近一次执行结果。

## 常见问题与注意事项

### 1. 为什么开启「直接修改壁纸」时提示需要文件访问权限？
为了在您关闭总开关（或切换模式）时能够把车机桌面恢复成您原来的壁纸，应用在首次开启前需要读取并备份当前系统壁纸。
- 请按弹窗引导授予文件访问权限；
- 如果您当前车机使用的是**动态壁纸**或**车机百变主题**导致系统无法读取原壁纸，也可以选择 **「不备份继续」**（此情况下关闭开关后不会自动复原原壁纸）。

### 2. 在「直接修改壁纸」模式下导入视频为什么显示「仅动态模式」？
应用不限制您随时导入视频文件，但系统的静态桌面接口不支持播放视频。  
处于「直接修改壁纸」模式时，已导入的视频会保留在列表中并标记为「仅动态模式」，实际切换时会自动跳过视频仅使用图片；切换到 **「动态壁纸模式」** 并激活后即可正常使用视频壁纸。

### 3. 导入视频时弹出「高规格视频提示」是什么意思？
为避免车机长期在桌面循环播放高负载视频导致发热或卡顿，当视频同时满足以下 **任意 2 项及以上** 条件时，导入前会弹窗提醒：
- 分辨率 ≥ 2K
- 帧率 > 60 fps
- 时长 ≥ 60 秒
- 文件体积 > 100 MB

您可以根据车机性能选择 **「仍然导入」**、**「跳过高规格视频」** 或 **「取消」**。

### 4. 如何防止车机清理后台导致无法自动切换？
- 开启总开关后，应用会在通知栏保持一个低打扰后台服务通知（Android 13 及以上系统建议允许应用发送通知）。
- 如果您的车机系统带有后台清理或省电限制，建议在车机管家中将 **「深浅壁纸」** 加入后台保活 / 允许自启名单。

### 5. 如何查看或导出调试日志？
1. 在左侧导航栏进入 **「关于」** 页面（顶部也可进入功能与使用说明）。
2. 打开 **「调试日志」** 开关，下方会展开运行日志控制台。
3. 支持 **复制** 日志、**清空** 内存日志、切换本地保存 **目录**，或绑定系统目录 / U 盘并 **导出** 带时间戳的日志文件。
